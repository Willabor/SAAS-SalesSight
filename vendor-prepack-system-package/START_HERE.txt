🔥 CRITICAL INSIGHTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PREPACKS ARE COLOR-SPECIFIC
   Each box contains ONE COLOR ONLY in assorted sizes
   Example: "5 boxes Pack A (Black)" = 60 BLACK pieces, not mixed colors

2. COST CALCULATION PRIORITY IS CRITICAL
   When looking up costs:
   Step 1: Search in specified style (8501E)
   Step 2: Fall back to all vendor styles if not found
   ⚠️ Never average across different styles blindly!

   Why: Size 44W×32L exists in 8501B ($14) and 8501E ($17)
        Averaging gives $15.50 which is WRONG for Pack E

3. PACK E DEMONSTRATES COLOR OVERRIDE
   Style 8501B has 14 default colors
   But Pack E only comes in 3 colors: Black, Grey, White
   This shows packs can override style defaults

4. 70% OF VENDORS USE PREPACKS
   You cannot order individual SKUs from most vendors!
   Without proper configuration, buying recommendations will be wrong
